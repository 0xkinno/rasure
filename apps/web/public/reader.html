rasure reader

One file. Reads Arkiv directly. Built only from arkiv/schema.md. No server of ours is involved.

Rasure payloads are ciphertext, so this reader shows the public attributes only, applies the two trust rules from the schema (a ride counts only if its creator is a trusted dispatcher; an assignment counts only if the ride's dispatcher created it), and lists what is ignored.
